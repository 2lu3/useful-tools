次に与える日本語の試験問題テキストを整形・正規化して

# 入力仕様
- 問題文が与えられる
- 本文選択肢（1〜5など）を含む場合がある
- 組み合わせ選択肢（例: ①AとB ②BとC ...）を含む場合がある
- 解答を含む場合がある
- 範囲; 解説; などの補足行が含まれる場合がある

# 出力仕様
- 出力形式はplain text(markdownは使わない)で、コードブロックに出力する
- 改行と記載順序は保持する

# 処理ルール
- 組み合わせ選択肢行は全削除（全角・改行混在も対象）
- 問題と解答の選択肢の値はアラビア数字に正規化する
  - 対応表: A→1, B→2, C→3, D→4, E→5, F→6 …
  - 組み合わせ表がある場合はそれに基づいて変換
  - 例: 解答; ⑤（⑤がAとE）→ 解答: 1,5
  - もともと数値の場合は半角化のみ行う
  - 複数解答は半角カンマで区切り、空白は入れない
  - 注釈やコメントは保持
- 問題文、選択肢、解答、範囲、解説は削除せず、順序を保持する

# 出力例
入力
問題3. 異常子宮出血の記載で正しいものを2つ選べ

2. ...
3. ...
4. ...
5. ...
①AとB ②BとC ③CとD ④DとE ⑤AとE
解答; ⑤
範囲; ...
解説; ...
